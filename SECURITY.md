# Security policy

## Supported versions

Security fixes go to the latest minor release of the latest major version.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting:

**https://github.com/ANSCoder/Swift-Extension/security/advisories/new**

Include what you found, how to reproduce it, and the affected version. You can expect an acknowledgement within a few days and a fix or a clear answer as soon as it is understood.

## Scope

This package is client-side code with no networking, storage or third-party dependencies. Reports about crashes on untrusted input, unsafe API behavior, or the build and release pipeline are in scope.
