# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Welcome newcomers, assume good intent, give and accept feedback graciously, and focus on what is best for the project and the people using it.

Unacceptable behavior includes harassment, personal attacks, trolling, discriminatory language, publishing others' private information, and anything that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit, remove or reject comments, commits, issues and pull requests that do not follow this code, and may ban contributors who repeatedly or seriously break it.

## Reporting

Report problems privately through the maintainer's GitHub profile or by opening a private security advisory. All reports are reviewed and kept confidential.
